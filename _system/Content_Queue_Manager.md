# ⚙️ Content Queue Manager (큐 관리 시스템)

## 1. 핵심 목표 및 KPI 정의 (Outcome-Based Bundle)
*   **최종 목표:** 베트남인 학습자의 비즈니스 소통 능력 향상.
*   **핵심 KPI:** BCR (40%), ITAR (30%) 가중치를 기반으로 콘텐츠의 ROI를 측정합니다.

## 2. 데이터 피드백 루프 스키마 (Data Feedback Loop Schema)
이 스키마는 모든 콘텐츠 제작 과정에서 **실행 결과(Outcome Data)**를 자동으로 삽입하고 업데이트하는 역할을 합니다.
*   **필수 필드:** `Content_ID`, `Target_Topic`, `KPI_Weighting` (BCR/ITAR), `Actual_Outcome_Score` (실제 성과 점수), `Feedback_Notes` (다음 콘텐츠 개선 사항)

## 3. 비주얼 및 논리 표준 (Automated Precision Standard)
*   **색상 팔레트:** Deep Navy (`#000080`), Gold Accent (`#FFD700`)로 통일합니다.
*   **레이아웃 표준:** 베트남어와 중국어가 동시에 제시되는 **'교차 레이아웃(Cross Layout)'**을 기본으로 설정합니다.
