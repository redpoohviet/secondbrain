# 🚀 유튜브 숏폼 자동 업로드 및 배포 시스템 제안

본 산출물은 Writer와 Designer의 구체적인 영상 기획을 기반으로, **SEO 최적화된 메타데이터**와 **자동화된 배포 계획**을 포함하는 실행 가능한 템플릿입니다.

---

## 📦 1단계: SEO 최적화 업로드 템플릿 (숏폼용)

선택된 주제 **[직장인 실무 중국어 표현 마스터]**에 맞춰, 시청자의 클릭과 참여를 극대화하는 제목, 설명, 해시태그 조합을 제시합니다.

### 📝 A. 영상 제목 (Title - 최대 60자 권장)

**선택 옵션 (가장 후킹한 것을 선택):**

1.  🚨 **직장 상사에게 무시당하는 한국식 중국어 표현 3가지. 지금 당장 멈춰!** (고통 집중형, 긴급성 극대화)
2.  🤫 **원어민만 아는 직장인 생존 중국어! 회의에서 무조건 승리하는 실무 표현 5가지** (비밀/권위 강조형)
3.  🔥 **3개월 만에 끝내는 직장인 필수 중국어: 업무 상황별 생존 표현 마스터법** (학습 로드맵 제시형)

### 📝 B. 영상 설명 (Description - 상세 정보 및 CTA 포함)

**(선택한 제목을 기반으로 아래 내용을 조합하여 사용하세요.)**

```
[핵심 후킹 문구 반복] 직장 상사에게 무시당하는 한국식 중국어 표현 3가지! 😱 이 표현들만 알아도 당신의 업무 능력이 달라집니다.

📌 **이 영상에서 배우는 것:**
✅ 회의 시 발언권을 얻는 정중한 요청법 (보고 지연 시)
✅ 의견을 명확하게 제시하는 자신감 있는 표현
✅ 거절할 때 무난하고 프로페셔널하게 말하는 법

🚀 **jinny's Lab의 특별함:** 단순 단어 암기가 아닌, 베트남 직장인이 실제로 써먹는 '뉘앙스'와 '실무 적용법'을 제공합니다.

📚 **다음 단계 (Call to Action):**
더 깊은 실무 중국어를 원한다면? 👇
[🔗 전체 마스터 코스 링크 삽입]

#중국어 #직장인중국어 #중국어공부 #베트남직장인 #업무중국어 #중국어학습 #실용중국어 #자기계발
```

### 📝 C. 해시태그 조합 (Hashtags - 최대 15개 권장)

**[핵심 키워드 + 타깃 + 채널 성격]의 균형을 맞춥니다.**

*   **필수 키워드 (Niche/Topic):** `#중국어` `#직장인중국어` `#업무중국어`
*   **타깃 키워드 (Audience):** `#베트남인` `#베트남직장인` `#Koreandutch` (또는 관련 지역 태그)
*   **행동 유도 키워드 (Actionable):** `#자기계발` `#업무팁` `#중국어학습`
*   **채널 성격 키워드 (Branding):** `#jinnyLab`

## 🗓️ 2단계: 자동화된 배포 계획 및 실행 플로우

시간을 줄이고 일관성을 유지하기 위해, **`auto_planner`**와 **`telegram_notify`** 도구를 활용하여 무인 반복 실행 시스템을 구축합니다.

### ⚙️ 자동화 플로우 설계 (Automated Flow)

| 단계 | 작업 내용 | 사용 도구 | 주기/트리거 | 목적 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 트렌드 분석** | `trend_sniper` 실행 → 최신 떡상 키워드 및 후킹 패턴 수집 | `trend_sniper` | 매일 새벽 (02:00) | 다음 영상 기획의 방향성 확보 |
| **2. 콘텐츠 생성** | 분석된 트렌드를 기반으로 Writer/Designer 산출물 재요청 및 최종 스크립트 확정 | (인간 개입 필요) | 주 1회 또는 신규 아이디어 발생 시 | 고품질 원고 확보 |
| **3. 메타데이터 생성** | 기획안을 바탕으로 SEO 제목, 설명, 해시태그 조합 자동 생성 | (AI 자체 처리) | 영상 완성 직후 | 업로드 준비 완료 |
| **4. 업로드 실행** | 최종 콘텐츠 및 메타데이터를 YouTube에 업로드 | `youtube_account` (내부 연동 가정) | 주 3회 또는 요청 시 | 채널 노출 극대화 |
| **5. 반응 모니터링** | 경쟁사/내 영상 반응을 수집하여 다음 전략 보완 | `my_videos_check`, `comment_harvester` | 매일 (09:00) | 데이터 기반 개선점 도출 |
| **6. 보고 및 알림** | 주요 분석 결과 및 다음 액션 브리프를 메신저로 전송 | `telegram_notify` | 주기적 실행 후 | 실시간 의사결정 지원 |

### ⏱️ 권장 배포 스케줄 (Weekly Batching)

콘텐츠의 질을 유지하면서 자동화를 극대화하기 위해 **주간 배치(Weekly Batching)** 방식을 제안합니다.

*   **요일:** 매주 화요일 또는 수요일
*   **실행 시간:** 오전 10:00 (업무 시작 후 집중도가 높아지는 시간)
*   **배포 주기:** 주 2회 (Shorts 중심)
    *   **1차 배포:** 고부가가치 '생존 표현' 시리즈 (심층 학습 콘텐츠)
    *   **2차 배포:** 트렌드 기반의 가벼운 실무 팁 (빠른 유입 확보 콘텐츠)
