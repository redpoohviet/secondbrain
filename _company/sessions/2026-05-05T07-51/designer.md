# 💎 jinny's Lab 비주얼 시스템 설계: Automated Precision

본 문서는 **jinny's Lab**의 브랜드 정체성('Automated Precision')을 유튜브 숏폼 콘텐츠에 자동 적용할 수 있도록 정의된 시각적 가이드라인 및 템플릿 구조입니다. 모든 콘텐츠는 이 시스템을 기반으로 제작되어야 하며, 디자인 작업 시간을 최소화하고 일관성을 극대화합니다.

---

## 1. 브랜드 비주얼 원칙 (Visual Principles)

**핵심 철학:** 명확한 정보 전달(Precision)과 학습의 여정(Lab)을 시각적으로 연결하여, 타깃 청중(3040 베트남인 직장인)에게 신뢰감과 즉각적인 실용성을 제공한다.

| 원칙 | 설명 | 적용 목표 |
| :--- | :--- | :--- |
| **명확성 (Clarity)** | 복잡한 정보도 1초 안에 이해 가능하도록 시각적 계층 구조를 엄격히 적용한다. | 시청 지속 시간 극대화 |
| **전문성 (Precision)** | 불필요한 장식을 배제하고, 데이터와 핵심 메시지에 집중하는 미니멀하고 구조적인 디자인을 추구한다. | 신뢰도 및 권위 확보 |
| **몰입 (Engagement)** | 학습 과정에서 오는 지루함을 없애기 위해 역동적인 움직임과 대비되는 색상을 사용하여 시각적 흥미를 유발한다. | 참여율(Engagement) 극대화 |

---

## 2. 디자인 시스템 정의 (Design System Definition)

### A. 컬러 팔레트 (Color Palette)

브랜드의 전문성과 학습의 활력을 동시에 표현하는 대비되는 조합을 사용합니다.

| 역할 | 색상 이름 | HEX 코드 | CMYK/RGB | 용도 및 의미 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary (핵심)** | Deep Navy Blue | `#0A1931` | C:95 M:82 Y:0 K:76 / R:10 G:25 B:49 | 전문성, 신뢰감, 깊은 학습 내용 강조 (배경 및 텍스트 본문) |
| **Accent (강조)** | Bright Gold | `#FFC300` | C:0 M:20 Y:100 K:0 / R:255 G:195 B:0 | 핵심 키워드, 후킹 문구, 성공 지표 강조 (시선 집중) |
| **Secondary (보조)** | Crisp White | `#FFFFFF` | 0 / 0 / 0 / 0 | 정보의 명료성 확보 (텍스트 박스 배경, 주요 구분선) |
| **Neutral (보조)** | Light Gray | `#EAEAEA` | 0 / 0 / 0 / 10 | 보조 설명, 배경 분리선, 차트 영역 (정보의 위계 정리) |

### B. 타이포그래피 시스템 (Typography System)

가독성과 계층 구조를 최우선으로 합니다. 산세리프체(Sans-serif) 기반으로 통일성을 유지합니다.

| 역할 | 폰트 명 | 스타일 | 용도 및 크기 가이드 |
| :--- | :--- | :--- | :--- |
| **Title/Hook (후킹)** | Pretendard Bold | Large, Heavy Weight | 시청자의 즉각적인 주의를 끌어야 하는 가장 큰 문구. (최대 72pt) |
| **Body Text (본문)** | Pretendard Medium | Regular | 핵심 정보 전달 및 설명에 사용되는 본문. (16~20pt) |
| **Data/Accent** | Pretendard SemiBold | Medium | 통계, 강조 포인트, 핵심 숫자 강조 시 사용. (18pt 이상) |

### C. 템플릿 구조 (Template Structure: Short-Form Standard)

숏폼 영상의 높은 몰입도를 위해 '정보 제시 → 감정 자극 → 해결책'의 3단계 흐름을 강제하는 표준 레이아웃을 정의합니다.

#### **[Template A: Hook & Solution (최대 몰입형)]**
*   **목표:** 최대의 후킹 및 즉각적인 가치 전달.
*   **레이아웃:** 화면 전체를 대비되는 색상(Deep Navy Blue 배경)으로 채우고, 핵심 텍스트와 강조 색상을 중앙에 배치합니다.
*   **구성 요소:**
    1.  **Top Banner (0-3초):** Primary Color 배경 위에 Accent Color로 가장 충격적인 후킹 문구 노출. (예: "❌ 실수하고 있나요?")
    2.  **Core Value Block (4-15초):** 핵심 3가지 표현이나 공식이 크게 배치됨. Gold 색상으로 키워드 강조.
    3.  **Action Call (16초 이후):** 다음 단계(Save/Follow) 유도를 위한 명확한 지시.

#### **[Template B: Deep Dive & Context (정보 밀도형)]**
*   **목표:** 상세하고 체계적인 정보를 구조적으로 전달.
*   **레이아웃:** 배경은 Light Gray 또는 White를 사용하여 가독성을 높이고, 정보 블록을 명확하게 분리합니다.
*   **구성 요소:**
    1.  **Header (상단):** 주제 제목 및 영상의 맥락 정의.
    2.  **Segment Blocks (중앙):** 각 표현이나 규칙을 별도의 카드(Card) 형태로 구성. 각 카드는 Primary Color 테두리를 가지며, 아래에 상세 설명이 배치됩니다. (정보를 3~4개 블록으로 분할하여 시각적 피로도 감소)
    3.  **Footer (하단):** 출처(jinny's Lab) 및 다음 영상 예고 문구.

## 3. 자동화 적용 가이드라인 (Automation Guidelines)

이 시스템을 기반으로 모든 콘텐츠 제작 시, 다음의 프로세스를 따릅니다.

1.  **입력:** 최종 스크립트 또는 핵심 키워드 입력.
2.  **분석:** AI가 입력된 내용을 **'고통(Pain Point)'**과 **'해결책(Solution)'**으로 분리하여 분석합니다.
3.  **디자인 매핑:** 분석 결과에 따라, 가장 적합한 템플릿(Template A 또는 B)을 자동 선택합니다. (예: 실무 표현 마스터 → Template A 적용)
4.  **렌더링:** 시스템 정의된 컬러 코드, 폰트 크기, 레이아웃 좌표를 기반으로 최종 디자인을 생성합니다.
