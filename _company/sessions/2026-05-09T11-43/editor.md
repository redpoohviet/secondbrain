# 🎬 최종 영상 편집 디렉션 및 B-roll 리스트 확정

본 지시사항은 YouTube 에이전트가 기획한 '고강도 경고형 (The Warning Flare)' 프레임워크를 기반으로, 최고 전환율(CTR)과 시청 지속률(Retention)을 극대화하기 위한 최종 편집 방향성과 구체적인 B-roll 리스트를 확정합니다.

---

## 1. 영상 편집 디렉션 (The Warning Flare 적용)

**▶️ 전체 톤:** 긴급함, 충격, 즉각적인 행동 촉구.
**▶️ 핵심 시각 전략:** **초고속 전환(Hyper-Paced Transitions)** 및 **극단적인 색상 대비(High Contrast Color Grading)**를 사용하여 시청자의 주의를 단 1초도 놓치지 않도록 한다.

### A. 컷 리듬 및 속도 가이드라인
1.  **후크 구간 (0:00 - 0:05):** 극도로 빠름. 컷 간격은 **0.5초 이내**. 화면 전환 시 강한 충격 효과(Whip Pan, Flash)를 사용하여 긴급성을 극대화한다.
2.  **문제 제기 구간 (0:05 - 0:15):** 빠른 리듬 유지. B-roll 클립은 1~2초 내외로 매우 짧게 사용하며, 텍스트와 영상의 타이밍을 완벽하게 일치시켜 메시지의 강도를 높인다.
3.  **해결책 제시 구간 (0:15 - 끝):** 속도는 약간 안정되나 여전히 역동적이다. 데이터 시각화(차트)는 명확하고 깔끔하게 보여주되, 배경에는 경고의 색상(빨강/주황)을 지속적으로 유지하여 긴장감을 놓치지 않는다.

### B. 색상 및 그래픽 가이드
*   **색상 팔레트:** 주된 색상은 **강렬한 빨간색 (Warning Red)**과 대비되는 **차가운 파란색/검은색 (Cool Blue/Black)**을 사용한다. 이 두 색상의 극단적인 대비를 통해 '위험'과 '통제'의 메시지를 시각적으로 각인시킨다.
*   **텍스트 강조:** 모든 핵심 키워드(STOP, 낭비, 위험)는 **굵고 튀는 서체**와 함께 **빨간색 테두리 또는 하이라이트 효과**를 적용한다.

### C. 자막 및 타이틀 전략
*   **자막 스타일:** 짧고 간결하게 끊어 읽게 유도한다. 문장을 통째로 보여주기보다, 핵심 단어만 강조하며 화면에 빠르게 등장시키고 사라지게 한다. (예: "시간 낭비" $\rightarrow$ '시간' 강조 후 '낭비'를 빨간색으로 처리).
*   **오디오 싱크:** 나레이션의 가장 중요한 단어나 구절이 화면 전환 시점에 정확히 일치하도록 편집한다.

## 2. 최종 B-roll 리스트 (실행 가능 목록)

아래 리스트는 스크립트의 각 섹션에 필요한 장면을 즉시 촬영하거나 확보해야 하는 구체적인 지시사항입니다.

| 시간대 | 나레이션 내용 기반 주제 | 요구되는 B-roll 유형 (구체적 액션) | 시각적 효과/스타일 가이드 |
| :---: | :--- | :--- | :--- |
| **0:03 - 0:10** | "시간과 에너지의 낭비" | 1. 초고속으로 돌아가는 시계 클로즈업 (슬로우 모션 또는 빠른 속도) | 흐릿함(Blur) 효과 사용, 불안정한 느낌 부여. |
| | | 2. 복잡하게 쌓인 서류나 업무 파일들이 무질서하게 흩어져 있는 장면 | 어둡고 답답한 톤 유지. |
| **0:10 - 0:25** | "시스템적 오류, 잠재력 상실" | 3. 복잡하고 혼란스러운 디지털 데이터 화면 (코드, 그래프의 과부하) | 붉은색 오버레이(Overlay) 적용하여 위협감 강조. |
| | | 4. 어둠 속에서 밝게 빛나는 하나의 스위치나 버튼을 찾는 손의 움직임 | 미스터리하고 탐색하는 느낌 부여. (빛과 그림자 대비 극대화) |
| **0:25 - End** | "통제권 회복 및 경고" | 5. 통제된 환경 속에서 명확한 목표를 향해 나아가는 움직임 (예: 정밀하게 조작하는 손, 깨끗한 작업 공간) | 차분하지만 단호한 느낌의 미니멀한 B-roll로 전환하여 신뢰도 확보. |
| | | 6. 빨간색 경고등이 빠르게 깜빡이는 클로즈업 또는 시스템 오류 메시지 화면 | 최종적으로 '경고'와 '해결책'을 동시에 시각화. |
