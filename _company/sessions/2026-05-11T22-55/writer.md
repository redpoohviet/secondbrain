# 🔥 손실 강조형 숏폼 영상 제작 프레임워크 (The Loss Aversion Pipeline)

이 프레임워크는 **[기획] → [카피라이팅] → [시각화]**의 세 단계로 구성되며, 모든 단계에서 `#FF8C00` 디자인 시스템과 손실 강조 원칙을 최우선으로 적용합니다.

## 1단계: 입력 및 전략 설정 (Input & Strategy Setup)

이 단계는 콘텐츠의 방향성과 감정적 목표를 명확히 설정합니다.

| 항목 | 내용 | 적용 기준 |
| :--- | :--- | :--- |
| **A. 주제 선택** | 레오가 제시한 5가지 기획안 중 하나 선택 (예: 영상 기획 1: 시간 부족 회피) | **최대 손실 강조**를 목표로 하는 주제 선택. |
| **B. 핵심 손실 정의** | 시청자가 놓치게 될 '손실'을 구체적인 금액, 기회 상실, 혹은 사회적 낙인으로 명확히 정의합니다. (예: 5년 뒤 연봉 잠재력 상실) | 감정적 연결(Fear/Anxiety) 극대화. |
| **C. 시각 목표 설정** | 디자인 시스템을 적용할 구체적인 비주얼 콘셉트를 정의합니다. | **디자이너의 JSON 템플릿 참조:** `primary_color: #FF8C00`, `transition_speed: 0.5s~1.0s`. |
| **D. 최종 목표** | 이 영상 시청 후 시청자가 즉시 취해야 할 행동(CTA)을 정의합니다. (예: 앱 다운로드, 특정 정보 검색 등) | 명확하고 긴급한 행동 유도. |

## 2단계: 후크 및 스크립트 초안 제작 (Hook & Script Drafting)

이 단계에서는 1단계의 전략을 기반으로 실제 시청자를 사로잡는 카피와 구체적인 장면 지시를 작성합니다. **후크(Hook)**는 영상 시작 **3초 이내**에 모든 감정적 충격을 전달해야 합니다.

### 🎬 A. 강력한 후크 (The Loss Hook) 제작 가이드

*   **구조:** [충격적인 질문/선언] + [손실의 구체화] + [즉각적인 해결책 암시]
*   **톤앤매너:** 경고(Warning), 긴급성(Urgency), 공포(Fear).
*   **적용 공식:** "당신이 (현재 상태)를 지속하면, 당신은 (구체적인 손실)을 잃게 됩니다. 지금 바로 이길 수 있는 유일한 방법은..."

### 📝 B. 영상 스크립트 초안 작성 (Script Drafting Template)

모든 스크립트는 **[화면 지시]**와 **[오버레이 텍스트]**를 분리하여 작성하며, 시각적 충격이 카피라이팅을 보조하도록 설계합니다.

| 시간대 | 비주얼 설명 (Visual Description - #FF8C00 강조) | 오버레이 텍스트 (Text Overlay - 흰색/강렬하게) | 내레이션/음향 지시 |
| :--- | :--- | :--- | :--- |
| **0.0s - 1.0s** | **[초고속 전환]** 배경 `#FF8C00`의 강렬한 화면 충격. 핵심 경고 문구가 즉시 등장. | **STOP! 🚨 당신의 돈을 잃고 있습니다.** | 긴박하고 날카로운 효과음 삽입. (Hook 발동) |
| **1.0s - 5.0s** | 문제 상황(손실)을 인포그래픽 또는 극단적인 대비 화면으로 제시. 데이터가 손실로 표현됨. | 당신이 놓치고 있는 3가지 기회! | 문제의 심각성을 강조하는 단호한 목소리. |
| **5.0s - End** | 해결책(앱/방법)을 제시하며 시각적 전환 속도 유지. CTA를 명확히 제시. | [해결 방법] 지금 바로 확인하세요! (CTA 버튼 강조) | 자신감 있고 확신에 찬 어조로 마무리. |

## 3단계: 최종 검토 및 적용 (Final Review & Application)

1.  **일관성 점검:** 작성된 스크립트의 감정선이 1단계에서 정의한 '손실 강조' 전략과 디자인 시스템(`#FF8C00`, 초고속 전환)에 완벽하게 부합하는지 검토합니다.
2.  **후크 테스트:** 영상 시작 3초 내에 시청자의 스크롤을 멈추게 할 만큼 강력한 후크 문구가 포함되었는지 확인합니다.
3.  **CTA 최적화:** CTA는 '부드러운 권유'가 아닌, '손실 회피를 위한 즉각적인 행동 명령'으로 작성되었는지 검증합니다.
