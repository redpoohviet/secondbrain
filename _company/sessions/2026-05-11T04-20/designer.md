## A/B 테스트 썸네일 컨셉 3안 (High Intensity Warning)

**핵심 원칙:**
1. **컬러:** 배경은 어두운 톤(Deep Black 또는 Dark Grey), 강조색으로 `#FF8C00` 사용, 보조 색상으로 순백색(`FFFFFF`)을 사용하여 극단적인 대비를 구현합니다.
2. **스타일:** 시선 흐름은 경고(Warning) → 핵심 키워드 → 행동 유도 요소 순서로 구성하며, 모든 텍스트 전환 속도는 1초 이내로 설정하여 긴급성을 유지합니다.
3. **레이아웃:** 시각적 피로도를 최소화하고 메시지 전달의 즉각성을 극대화하는 레이아웃을 사용합니다.

### 컨셉 1: 시간 압박형 (The Time Crunch) - 가장 강력한 경고

| 항목 | 상세 내용 | 디자인 지시사항 (Visual Prompt Focus) |
| :--- | :--- | :--- |
| **주제** | "시간 통제" 메시지 극대화 | 시계, 카운트다운, 금지 표시 아이콘 활용. |
| **배경** | 짙은 검정 (`#0A0A0A`) | 깊고 어두운 분위기 조성. |
| **강조색** | `#FF8C00` | 모든 핵심 텍스트와 경고 라인에 사용. |
| **텍스트 레이아웃** | 중앙 상단에 큰 경고 문구, 하단에 행동 유도 버튼/화살표 배치. |
| **폰트 스타일** | 매우 두껍고 각진 산세리프체 (예: Impact 또는 Bold Sans-serif). 폰트 색상은 흰색(`FFFFFF`)과 주황색(`#FF8C00`)으로 명확히 구분. |
| **모션 시퀀스** | 배경이 빠르게 깜빡이며 경고 표시가 순간적으로 나타났다가 사라지는 효과 (1초 이내 전환). |

### 컨셉 2: 안전/해결 강조형 (The Safety Solution) - 즉각적 안도감 유도

| 항목 | 상세 내용 | 디자인 지시사항 (Visual Prompt Focus) |
| :--- | :--- | :--- |
| **주제** | "안전 확보" 메시지 극대화 | 문제(Warning Icon)에서 해결(Check Mark/Shield)로의 시각적 흐름. |
| **배경** | 중간 톤의 다크 그레이 (`#333333`) | 컨셉 1보다 약간 부드러우나 여전히 긴장감을 유지. |
| **강조색** | `#FF8C00` 및 흰색(`FFFFFF`) | '문제' 부분에 주황색 경고, '해결책' 부분에 흰색 강조. |
| **텍스트 레이아웃** | 좌측에 문제 상황(작은 폰트), 중앙에 해결책 문구(매우 큰 폰트), 우측에 결과 아이콘 배치. |
| **모션 시퀀스** | 왼쪽에서 오른쪽으로 점진적으로 변화하는 모션 (Warning → Solution). 핵심 전환 시점에 주황색이 섬광처럼 터지는 효과. |

### 컨셉 3: 고강도 대비형 (The Extreme Contrast) - 스타일 중심의 충격

| 항목 | 상세 내용 | 디자인 지시사항 (Visual Prompt Focus) |
| :--- | :--- | :--- |
| **주제** | 순수한 시각적 자극 및 스타일 강조 | 색상과 텍스트 대비만을 극대화. |
| **배경** | 순수 검정 (`#000000`) | 최대의 어둠. |
| **강조색** | `#FF8C00` (주요 요소) 및 `FFFFFF` (보조 요소) | 두 색상의 대비를 90% 이상으로 설정. |
| **텍스트 레이아웃** | 중앙에 하나의 거대한 단어 또는 핵심 문구만 배치하며, 주변 여백을 최소화하여 밀도를 높임. |
| **모션 시퀀스** | 배경색과 강조색의 급격한 색상 전환(Flash) 및 텍스트가 화면 전체를 채우는 빠른 확대/축소 효과. |
