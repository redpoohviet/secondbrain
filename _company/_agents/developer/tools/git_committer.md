# 💾 Git Committer (작업 단위 자동 커밋)

개발자 에이전트가 작업을 마칠 때마다 의미 있는 단위로 코드를 저장하게 돕는 도구입니다.

## 주요 기능

- **자동 스테이징**: `git add .`를 실행하여 모든 변경 사항을 준비합니다.
- **메시지 규칙**: 설정된 접두어(feat, fix, chore 등)를 사용해 커밋 로그를 깔끔하게 유지합니다.
- **안전 검사**: 커밋할 내용이 없을 경우 중복 커밋을 방지합니다.

## 설정 (git_committer.json)

| 키 | 설명 | 기본값 |
|---|---|---|
| `DEFAULT_MSG` | 별도 인자가 없을 때 사용하는 커밋 메시지 | `feat: auto-commit...` |
| `AUTO_STAGE` | 커밋 전 `git add .` 실행 여부 | `true` |
| `PRE_COMMIT_LINT` | 커밋 전 린트 체크 실행 여부 (준비 중) | `false` |

## 사용 방법

에이전트가 작업을 완료한 후 다음과 같이 호출합니다.
```bash
python git_committer.py "feat: 에이전트 설정 기능 추가"
```

## 안전 규칙

- `git push`는 포함되어 있지 않습니다. 푸시는 항상 대표님의 최종 승인 후 별도의 배포 도구를 통해 진행합니다.
- 중요한 환경 설정 파일(`.env`, `config.md` 등)이 `.gitignore`에 포함되어 있는지 항상 확인하세요.
