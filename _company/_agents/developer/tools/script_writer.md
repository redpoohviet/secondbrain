# 📝 Script Writer (세션 폴더 저장형)

에이전트 간 논의가 이루어진 **현재 세션 폴더**에 직접 파이썬 코드를 구현하고 저장하는 스킬입니다.

## 주요 특징

- **세션 동기화**: 별도의 외부 폴더가 아닌, `_company/sessions/YYYY-MM-DDTHH-MM/` 폴더 안에 코드를 저장합니다.
- **맥락 유지**: 논의 기록(`.md`)과 코드(`.py`)가 같은 곳에 있어 나중에 복기하기 매우 좋습니다.
- **자동 감지**: 별도의 경로 지정 없이도 가장 최근 세션 폴더를 자동으로 찾아 들어갑니다.

## 사용 방법

에이전트가 논의를 마친 후:
```bash
python script_writer.py "analysis.py" "print('Processing session data...')"
```

## 워크플로우

1. **소통**: 대표님 또는 다른 에이전트와 특정 세션에서 대화합니다.
2. **구현**: 개발자 에이전트가 대화 내용을 요약하고 코드를 짭니다.
3. **저장**: 본 스킬을 통해 해당 세션 폴더에 `.py` 파일을 생성합니다.
4. **확인**: 대표님은 세션 폴더 내에서 대화 기록과 결과물 코드를 한꺼번에 확인하실 수 있습니다.
