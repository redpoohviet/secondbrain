# 🏹 Hook & CTA Library Manager

작가 에이전트의 핵심 자산인 **고효율 후크(Hook)와 행동 유도 문구(CTA)**를 관리하는 도구입니다.

## 주요 기능

- **라이브러리 축적**: 반응이 좋았던 후크나 새로운 아이디어를 지속적으로 저장합니다.
- **맞춤형 조회**: 현재 쓰고 있는 글의 주제에 맞는 후크를 목록에서 골라 쓸 수 있습니다.
- **성과 추적**: (향후) 각 문구의 클릭률이나 반응도를 함께 기록할 수 있습니다.

## 설정 (hook_library.json)

별도의 외부 API 키가 필요하지 않으며, 모든 데이터는 이 JSON 파일에 로컬로 저장됩니다.

## 사용 방법

에이전트가 글을 쓰기 전이나 후에 다음과 같이 호출합니다.

**목록 보기**
```bash
python hook_manager.py list
```

**새로운 후크 추가**
```bash
python hook_manager.py add_hook "당신이 밤잠 설칠 정도로 고민하는 그것, 해결책은 의외로 간단합니다."
```

## 워크플로우 제안

1. **학습**: 대표님의 과거 인기 게시물에서 후크를 추출하여 `add_hook`으로 저장합니다.
2. **제작**: 새로운 대본을 쓸 때 `list` 명령으로 기존 라이브러리에서 가장 적합한 후크를 추천합니다.
3. **업데이트**: 대표님이 수정한 최종 후크를 다시 라이브러리에 업데이트하여 톤앤매너를 유지합니다.
